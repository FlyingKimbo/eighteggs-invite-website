🎮 Data Collection in Detail

In the 8Eggs Mobile App:

  • User & Device IDs: Anonymous identifiers generated for your game account
  • Display Names: Player-chosen names for leaderboards (minimum 3 characters)
  • Game Progress Data: Scores, levels unlocked, achievements, game settings
  • Purchase Receipts: Self-formatted Google Play purchase receipts stored for verification and anti-fraud purposes
  • Device Information: Basic device model, OS version for AdMob ad compatibility

On Our Website (invite.888solutions.info):

  • Friend Referral Codes: From URL parameters (e.g., ?friend_code=ABC123)
  • Install Click Events: To track successful game installations
  • Browser Information: For website compatibility and optimization

💾 Data Storage & Security

All data is stored securely with the following measures:

  • Primary Storage: Supabase databases with encryption at rest
  • Data Transmission: All data encrypted in transit via HTTPS/SSL
  • Local Storage: Some game data cached locally on your device
  • Purchase Receipts: Stored in Supabase for purchase verification and fraud prevention
  • Data Location: Stored in secure cloud servers with access limited to essential personnel

🎯 Data Usage Purposes

We use collected data exclusively for:

  • App Functionality: Game features, progress saving, leaderboards
  • Account Management: User account creation, identification, and management
  • Advertising: Displaying AdMob advertisements (non-personalized)
  • Purchase Verification: Validating in-app purchases and preventing fraud
  • Referral System: Tracking friend invitations and rewards
  • App Improvement: Bug fixes and performance optimization

👥 Third-Party Services & Data Sharing

Services We Use:

  • Google AdMob: For displaying advertisements in our app
  • Google Play Billing: For processing in-app purchases (we only receive purchase receipts)
  • Supabase: For secure database storage and backend services
  • GitHub Pages: For hosting our invitation website

Data Sharing Policy:

  • ✅ We share device information with AdMob for ad display
  • ✅ We share purchase data with Google Play for transaction processing
  • ❌ We do NOT sell your data to third parties
  • ❌ We do NOT share personal information with advertisers
  • ❌ We do NOT share data for marketing purposes

⏱️ Data Retention & Deletion

  • Account Data: Retained until you request deletion
  • Purchase Records: Retained for 3 years for financial compliance
  • Deletion Requests: Processed within 7 days, fully removed within 30 days
  • Backup Data: Encrypted backups retained for up to 90 days

Note: Some purchase data may be retained longer for legal/financial compliance requirements.
